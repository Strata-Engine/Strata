Task 1: Ruling: `rule`'s second parameter is named `curves`, not `by` (GAPS S2: `by` cannot be a name); its meaning is the brief's — controller ruling — none.
Task 1: Ruling: built-in ground fields are declared by the game with `field_ground(p, name, slot)`; a slot outside 0..9 is a freeze error — controller ruling — none.
Task 1: Ruling: fields, zones, shape sets and layers are four namespaces; a name is unique within its kind only — controller ruling — none.
Task 1: Ruling: `Frozen` keeps every kind as a list in declaration order (layers in run order) beside a list of its names, and every reference as an index into those lists (a cover field holds its layer's run-order index); later tasks turn what they evaluate per column into arrays — lists are walked by index, which is linear; a task that reads a list per column must first copy it into an array.
Task 1: Ruling: `curve` sorts its points by x with List.sort_by, which is stable, so points at one x keep the order given and make a step: below it the curve approaches the first, at and above it reads the last (fix round 1 made `x == x0` read on, so the later point wins at its x; tested both ways round) — the brief says only "piecewise linear" — none.
Task 1: Ruling: a scatter cell must be above 0 (0 is refused as well as negative: Strata.Feature divides by it), and jitter must be within 0..0.6 (below 0 is refused as well as above 0.6) — the brief names only "negative cell" and "above 0.6" — none.
Task 1: Ruling: a ring zone's inner and outer radii and every site's radius (in rings and site layers) are "radii" and are refused when negative; inner above outer is accepted (an empty ring) — none.
Task 1: Ruling: freeze also refuses curve fields that read each other in a cycle and zones made of each other in a cycle (both would loop forever when evaluated); the brief names only the cover cycle — none.
Task 1: Ruling: run order is "repeatedly the earliest declared layer whose read layers have all run", so a layer with no reads keeps its declared place relative to others and a reading layer runs at the first point after all it reads — other stable orders exist; this one is what the brief's examples give — none.
Task 1: Ruling: a layer's reads are the cover fields reached from its rule's curves and from the bands of its inside and outside zones (through zone_all, zone_any, zone_not and curve fields) — none.
Task 1: Ruling: `missing_ground` lists the slots of ground fields reached through curve chains from any layer's rule curves or from any declared zone's band, even a zone no rule uses, plus slot 7 whenever any `zone_regions` zone is declared (controller ruling, fix round 1); a curve field nothing reads does not count — a game may be asked to supply a slot only an unused zone needs.
Task 1: Ruling: a second `weights` for the same shape set and zone is refused as a duplicate, naming both (controller asked for a decision, fix round 1), so `shape_set_weights` holds at most one entry per zone, in declaration order; which entry applies where two weighted zones overlap is the placer's call (Task 3) — a game that wanted a later weights to override an earlier one must remove the earlier.
Task 1: Ruling: freeze evaluates all its checks and returns the first in this order: duplicates (fields, zones, shape sets, layers), fields, zones, shape sets, weights, duplicate weights, layers, field cycles, zone cycles, then the cover cycle — none.
Task 1: Ruling: noise kind and octaves are not checked here (Task 2 knows what `Strata.Noise` accepts) — none.
Task 1: Ruling: a layer also reads what the zones its shape set's weights are keyed to read, so a layer whose weights band another layer's cover runs after it, and a cycle through weights is refused like one through rules (controller ruling, fix round 1) — none.
Task 1: Ruling: freeze also refuses a noise period that is not above 0 (NaN included), a negative or NaN weight, weights summing to 0 (or NaN), and a rule base below 0 or NaN (controller ruling, fix round 1); comparisons are written so NaN fails them (`if v > 0.0 do false else true end`) — none.
Task 1: Ruling: evaluation and placement live in a second module, `Strata.Populate`, written by later tasks (controller ruling, fix round 1); `Strata.Population` exposes read accessors on `Frozen`: `field_count/names/index/kind/slot/noise_kind/octaves/period/salt/source/source_curve/layer/radius`, `zone_count/names/index/kind/ids/field/lo/hi/sites/inner/outer/members`, `shape_set_count/names/index/kind/blocks/templates/variants/weights`, `layer_count/names/index/kind/shape_set/salt/base/curves/inside/outside/cell/jitter/sites/margin`, `site_xm/zm/floor/radius/index`, `curve_points`, `curve_at`; kinds are numbers (fields 0 ground 1 noise 2 curve 3 cover; zones 0 regions 1 band 2 ring 3 all 4 any 5 not; shape sets 0 blocks 1 templates; layers 0 cover 1 scatter 2 site) so the consumer never matches a constructor (GAPS S5); an index out of range or a number the kind lacks reads -1, 0.0, Nil or an empty curve — each read walks a list, so the consumer reads once per chunk into arrays, never per column.
Task 1: Ruling: the module grew to about 930 lines with the accessors (one-line multi-arm matches do not parse, GAPS S32, so each reader is six lines); not split, since the controller's accessor ruling set the scope — none.
Task 2: Ruling: field and rule evaluation live in a new module `Strata.Populate` (`lib/strata/populate.march`, tests `test/populate_test.march`), so the brief's `Strata.Population.Ground`, `Table`, `ground`, `with_field`, `fields`, `field_at`, `zone_at`, `density_at` are `Strata.Populate.*` with the same signatures; `Strata.Populate` depends on `Strata.Population`, never the reverse — controller ruling — none.
Task 2: Ruling: a noise field is `Strata.Noise.settings(kind, octaves, 2.0, 0.5, 1, 0.0)` (lacunarity 2, gain 0.5, fBm, no warp) at frequency `1 / period`, seeded with `Strata.Seed.mix(seed, salt)`, and its value is mapped from [-1, 1] to [0, 1] by `0.5 + 0.5 * v`, so rules and curves read unit-range noise — controller ruling — none.
Task 2: Ruling: a column's world position in metres is its centre, `(x0 + i + 0.5) * voxel` (likewise z), where `voxel = scale * 2^level`; noise is sampled there, and `zone_ring` measures from there — controller ruling — two Grounds that overlap agree at shared columns (tested).
Task 2: Ruling: `zone_regions` reads ground slot 7 rounded to the nearest integer (`floor(v + 0.5)`) and compares it with the ids; slot 7 not supplied reads 0 — controller ruling — none.
Task 2: Ruling: `zone_ring` holds where `inner <= distance < outer` from some site's centre, half open like `zone_band`; `zone_all` of no zones holds everywhere, `zone_any` of none nowhere — implementer's call; the brief says only "between its radii" — none.
Task 2: Ruling: cover fields read 0 in Task 2; `eval_field` in `Strata.Populate` has a marked place ("COVER FIELDS (Task 6)") where Task 6 fills them — controller ruling — none.
Task 2: Ruling: per-column evaluation is by index: `density(t, layer_index, col)` and `in_zone(t, zone_index, col)` read the compiled Table; `density_at`, `zone_at`, `field_at` look names up and are for tests and tools. Zones are evaluated once per `fields` call into one byte per column per zone, in an order where a zone follows the zones it is made of, so `in_zone` is an array read — controller ruling — none.
Task 2: Ruling: rules are compiled per `fields` call (the brief says by `freeze`; evaluation moved out of `Strata.Population`), into a flat Int32 program and a Float array of bases and curve points the Table owns; compiling walks the Frozen's lists once per call, a cost of a few layers, not per column — implementer's call — a later task that wants it once per Frozen can cache the two arrays beside the Frozen.
Task 2: Ruling: `with_field` given a slot twice uses the later values; values shorter than n * n leave the rest of the field at 0; a density for a site layer is 0 (it has no rule); an index or column out of range reads 0 or false — implementer's call — none.
Task 2: Ruling: the cost test prints microseconds per call over 200 calls of `fields` plus 3 x 1024 `density` reads, and asserts nothing (the machine's load average was 70 to 150 while it ran) — controller ruling — a clean measurement is still owed.
Task 2: Ruling (fix round 1): `fields_with` evaluates every layer's density once over all the columns into the Table (base, times each curve of its field's array, 0 where a zone fails, clamped at 0 once per column; layer l at `l * nn` of one array), so `density(t, layer, col)` is one Bool range guard and one array read — controller ruling — supersedes "density reads the compiled program per column".
Task 2: Ruling (fix round 1): curves stay plain piecewise-linear code with Float-valued branches; March boxes a Float-valued `if` (march-language/march#1263, fix in progress) and Strata records the cost rather than dodging it with tables or arithmetic tricks; unnecessary Float-valued branches go (the three guards in `density` are one Bool guard) — controller ruling — the curve share of the cost is measured by bench/populate_fields.
Task 2: Ruling (fix round 1): `plan(f) : PopPlan` reads a Frozen once (field and zone evaluation orders, per-field and per-zone parameters, ids, members, sites, curve points and the compiled rule programs, all in flat arrays); `fields(f, seed, g)` is `fields_with(plan(f), seed, g)` for tests and tools; later tasks keep a plan. A plan is immutable; a caller sharing one between worker tasks unpacks what a loop needs before the loop (GAPS S15). The type is `PopPlan` because `Plan` is taken (Strata.Fluid, and the stdlib's DataFrame) — controller ruling — supersedes "rules are compiled per fields call".
Task 2: Ruling (fix round 1): a noise field is evaluated on world-aligned tiles of 32 x 32 columns: for each tile (tx, tz) the Ground touches, `field2` runs with origin `(32 * tx + 0.5) * voxel` (likewise z) and step `voxel`, computed from the tile's index only, and the Ground's columns are copied out; so two Grounds read the same bits at a shared column at any scale — controller ruling — a Ground not on tile boundaries pays for up to four tiles (a 32 x 32 chunk on boundaries pays one). Note: FastNoiseLite rounds coordinates to float, so the earlier per-Ground origin differed only when a double straddled a float rounding boundary (about 2^-29 a sample); the exactness tests pass against the old code too and guard the tile scheme against regressions rather than showing the old fault.
Task 2: Ruling (fix round 1): loops take n, x0, z0, voxel and arrays as arguments, never reading the Ground or the plan per column — controller ruling — none.
Task 2: Ruling (fix round 1): `problems(g) : List(String)` lists n not above 0, a scale not above 0 or NaN, tops or waters or a supplied slot not n * n long, and a slot outside 0..9, one message each; `fields` over a Ground with problems is a Table of zeros (nn 0, so every read is 0 or false) — controller ruling — supersedes "values shorter than n * n leave the rest at 0".
Task 2: Ruling (fix round 1): `freeze` refuses a noise kind outside 0..3 and octaves outside 1..16, naming the field; Task 1's deferral ("noise kind and octaves are not checked here") is closed — controller ruling — none.
Task 2: Ruling (fix round 1): a NaN region value, or one too large to round (|v| >= 10^15), matches no region; the half-open ring is confirmed — controller ruling — none.
Task 2: Ruling (fix round 1): the cost is measured by CPU time in bench/populate_fields (run.sh: REPS=n minus REPS=0 under /usr/bin/time -l, for march-main and forge's default toolchain); the unit test's wall-clock print is gone — controller ruling — figures below.
Task 2: Measurement (fix round 1, bench/populate_fields, REPS=2000, load average 37 to 47): `fields_with` over 32 x 32 columns with 4 fields and 3 layers (5 curve evaluations a column, one noise tile) costs 295 us of CPU and 5.9 M instructions a call under march-main (295 us, 6.1 M under forge's default 0.5.0), against the design's 0.1 ms. The curve code alone (5 passes over 1024 columns, the module's code copied) is 210 us and 4.6 M instructions; the same passes with a branch-free factor are 15 us, so about 195 us, two thirds of the call, is the curve's Float-valued branches (march#1263). The rest, about 85 us, is the noise tile, the copies, the zone and the density passes — the March-gap share is to be re-measured when march#1263 lands.
