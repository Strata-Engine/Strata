# Strata interface toolkit: plan

**Spec:** `docs/2026-11-19-gui-design.md`. Ledger: `docs/gui-ledger.md`.
Branch: `claude/recursing-volhard-8b2976`. Not merged into main.

## Constraints

- `Strata.Gui` is pure March; its tests link no C. Anything calling
  `Strata.Text` or `Strata.Ffi` lives in `Strata.GuiDraw`.
- Every viewer run uses `MARCH_PIN_MAIN=1`. Existing goldens stay as they
  are; the three physics goldens failing on main are not this work's.
- Slow March is fixed in March with a reproducer; C only as a marked stopgap.

### Task 1: layout

`lib/strata/gui.march`: node types, sizes, theme, the two layout passes,
layers and anchors. Tests: sizes along and across, padding, gap, anchors,
shares of the window, nested containers.

### Task 2: interaction

Hover, press, capture, click; focus order, next, previous, direction;
activation; sliders, toggles, buttons. Tests for each.

### Task 3: fields, scroll regions, choice lists

Typed text through `Strata.Controls.text_edit` with the caret in state;
viewport, wheel, thumb drag, focus kept visible, culling; the dropping
list as a top layer. Tests for each.

### Task 4: drawing and sampling

`lib/strata/gui_draw.march`: `paint`, `measurer`, `sample`. A shim call to
free and capture the cursor at runtime (`sv_set_cursor`).

### Task 5: the viewer's settings screen

F1 / pad right stick click; values applied by regenerating with overrides;
light mode; voxel scale; readout toggle. Golden scene `gui-settings`.

### Task 6: measurement and docs

Per-frame cost of the settings screen (build, run, paint) into
`RESULTS.md`; README section and modules table; ledger. Merge main, gate.
