# Rulings made while building plugins and strata_tactics
- Task 2: earlier owner wins a clash; the loser's binding is dropped and reported.
- Task 4: overlay items are pulled 3 cm toward the eye in the vertex shader (no z-fighting); "through" items are copied after the rest in the frame's buffer and drawn again with the depth test inverted at 35% opacity. Pass kinds 12 and 13; dropped count is `Strata.Ffi.Vk.stat(35)`.
- Task 5: a capsule hides only what is above its lower end, so the floor round the point it reaches stays (otherwise the camera's capsule to a unit would cut a hole in the ground round the unit). Cost if wrong: a game wanting a full capsule cut would need a flag.
- Task 5: the cut scene uses the existing ruin scene (129) sliced 2 m above the ground in a 24 m box plus a capsule, not a purpose-built house with a figure: it shows the same thing (walls and trees cut, the ground and shadows kept) without new scene-building code. Cost if wrong: figures' obeying the cut is unshown here (they use the same G-buffer shader).
- Task 5: known limitation: cut terrain shows the sky through its open interior (solid ground has no inner faces); a dark cap on cut solids is a follow-up. Cost: cut views of hillsides look hollow.
- Task 6: Ruling: the frame type is `Strata.Plugin.PluginFrame`, not `Frame` — March has one global type namespace and `Frame` was taken. The tactics grid's types are `TileGrid` and `GridSettings` (Strata.Body.Grid exists). Cost if wrong: names only.
- Tasks 4–5: Ruling: committed as one change — the overlay and cutaway edits interleave in strata_vk.c, ubo.glsl and the shader header (one generated file), so separate commits would not each build. Cost: one review range for both.
- Task 7: the grid's full build of 64 x 64 tiles (tile 4, scan 24 cells) takes 1510 ms in the test build against a 1000 ms budget (asserted at 4x). Reach 2 ms (budget 2), refresh after a radius-6 blast 13 ms (budget 16). To re-measure in release (Task 16); if still over, the cost is World.get_block per cell and the fix belongs in March/Strata (a column read).
- Task 9: Ruling: `on` and `within` are reserved words in March (the first is GAPS S4; `within` is new); the reach module's helper is `on_map`. Cost: none.
- Task 10: Ruling: lines of sight stop only at blocks that collide (Strata.Blocks.collides), not every drawn block, so water does not block sight. Cost if wrong: a game wanting glass to block sight registers it colliding.
- Task 10: Ruling: the five rays are the centres and the centres moved a quarter tile along each of the four diagonals.
- Task 11: picking with a cut starts the ray where it crosses the cut height; capsule cuts are not considered for picking.
- Task 12 research (The Ivalice Chronicles, Enhanced; 2026-11-20):
  - Turn cost: 60 a turn, +20 if the unit moved, +20 if it acted (Game8, "CT (Charge Time) Explained", https://game8.co/games/Final-Fantasy-Tactics/archives/543470). A Steam guide gives a different model (https://steamcommunity.com/sharedfiles/filedetails/?id=3581203978); the PS1 forum account (move+act 100, one of them 80, wait 60; https://gamefaqs.gamespot.com/boards/197339-final-fantasy-tactics/74387490) agrees with Game8, so 60/20/20 is the default.
  - Cap: Game8 says CT may pass 100 and the spillover is carried into the next turn; no source for the Ivalice Chronicles gives a cap after a turn. Ruling: no cap by default (`ck_cap = None`); the setting stays for games wanting the older cap. Cost if wrong: fast units bank slightly more CT than in the remake.
  - Tie-break: the order of units on the battle's unit list (GameFAQs, above) — the order units were added.
  - Charged actions: speed counts ticks (a 25-speed spell takes 4 ticks; Neoseeker, https://www.neoseeker.com/final-fantasy-tactics-the-ivalice-chronicles/Turn_Order_&_Charging_Abilities). The remake shortened charge times, which are content, not clock rules. No source gives the resolution order of two charges due on one tick. Ruling: the order they were queued. Cost if wrong: two simultaneous spells resolve in the other order.
  - Classic and Enhanced: no source separates them for these rules; both are taken to agree.
- Task 13: Ruling: yaw 0 puts the eye on the +z side looking toward -z; drag turns 0.3 degrees a pixel; zoom actions move the wanted distance 20 m/s and a wheel notch 2 m, the distance easing to it at 10/s; with tilt off the pitch is pitch_far. The camera starts halfway between near and far. Cost if wrong: feel only, all settings or one-line constants.
- Task 14: Ruling: a look shot moves the orbit's eye-to-focus offset to the point; shots travel over twice the turn time each way (smoothstep). Cost: feel only.
