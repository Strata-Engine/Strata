# Strata Save and Load Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Strata world kept on disk while it is played: edited chunks and queued edits in region files written by workers, a header with identity, the game's world sections and the entity snapshot, player records and region sections for the game's own data, loaded back settled, with seams where the generator changed.

**Architecture:** Pure March. `Strata.Savefile` encodes and decodes every file (bytes in, values out, never a panic). `Strata.Save` owns a store: the folder, its dirty regions, the writes in flight (as `Task`s, the way `Strata.Stream` runs work), and a cache of decoded regions. `Strata.World` gains a change log (off until a store is opened), a way to give up written chunks while keeping an eighth-size coarsening for the far field, and `Strata.Stream`'s generation tasks read saved regions instead of generating where the store has them.

**Tech Stack:** March, built with the toolchain `main`'s `scripts/env.sh` sets up (the newer March where file and settings calls go through `Authority.must`; see `lib/strata/atlas.march`'s cache for the idiom). Standard library `File` (`read`, `write`, `rename`, `delete`, `exists`), `Dir` (`mkdir_p`, `list`), `Bytes`, `Task`. No C.

**Spec:** `docs/2026-11-12-save-design.md`

## Review Focus

1. **The disk refuses a write** (full, read-only, the folder deleted while playing): the write fails, is counted and retried on the next dirty pass, the chunks stay in memory (nothing is dropped from `Strata.World` until its region is on disk), and nothing panics. Test: Task 4 ("write failure keeps chunks").
2. **A chunk edited back to its generated state:** its saved copy is removed from its region on the next write, and a region left with nothing in it has its file deleted, so a later load does not resurrect the old edit. Test: Task 4 ("edited back").
3. **Two games open one folder:** the second `open` refuses with a reason while the first holds it, through a lock file the store writes at open and removes at `close`; a lock left by a crashed game is taken over only when the game says so (`open_forcing`). Test: Task 2 ("lock").
4. **Hostile or truncated bytes:** any byte string given to any decoder answers `Ok` or `Err`, never a panic, and never allocates more than the input could describe (a length field larger than the rest of the input is an error, not an allocation). Test: Task 1 ("garbage decodes safely").
5. **A large game section** (several MB, such as a city's map) set every frame: only the latest value is written, on a worker, on the header interval; the frame cost of `set_section` does not grow with its size. Test: Task 4 ("big section").

### Task 1: Encoding

**Files:**
- Create: `lib/strata/savefile.march`, `test/savefile_test.march`, `docs/save-ledger.md`

**Interfaces — Produces** (`Strata.Savefile`, alias `Sf`):
```
type Writer                              -- an append-only byte buffer
fn writer() : Writer
fn put_u8 / put_u32 / put_i64 (w : Writer, v : Int) : Writer
fn put_f64(w : Writer, v : Float) : Writer
fn put_bytes(w : Writer, b : Bytes) : Writer        -- length-prefixed
fn put_string(w : Writer, s : String) : Writer      -- length-prefixed UTF-8
fn finish(w : Writer, magic : Int) : Bytes          -- magic (u32), format version (u8), body, checksum (u32) over magic..body
type Reader
fn reader(b : Bytes, magic : Int) : Result(Reader, String)   -- checks magic, version 1, checksum, length
fn get_u8 / get_u32 / get_i64(r : Reader) : Result((Reader, Int), String)
fn get_f64(r : Reader) : Result((Reader, Float), String)
fn get_bytes(r : Reader) : Result((Reader, Bytes), String)
fn get_string(r : Reader) : Result((Reader, String), String)
fn at_end(r : Reader) : Bool

type Header = { sh_seed : Int, sh_scale : Float, sh_fingerprint : Int, sh_generator : Int, sh_counter : Int,
                sh_sections : List((String, Bytes)), sh_entities : Option((NativeI32Arr, NativeF32Arr, NativeFloatArr)) }
type Region = { sr_generator : Int, sr_counter : Int, sr_chunks : List((Strata.Coord.Key, Strata.Chunk.Chunk)),
                sr_ops : List((Strata.Coord.Key, List(Strata.World.Op))), sr_sections : List((String, Bytes)) }
fn encode_header(h : Header) : Bytes      fn decode_header(b : Bytes) : Result(Header, String)
fn encode_region(g : Region) : Bytes      fn decode_region(b : Bytes) : Result(Region, String)
fn encode_player(b : Bytes) : Bytes       fn decode_player(b : Bytes) : Result(Bytes, String)
fn magic_header() : Int  fn magic_region() : Int  fn magic_player() : Int   -- three distinct u32 values
```
The checksum is CRC-32 (IEEE polynomial), in March. Little-endian throughout. A chunk is written in its own form: a form byte (0 uniform, 1 paletted, 2 direct, as `Strata.Chunk.form`) and that form's arrays; a decoded chunk passes through `Strata.Chunk.compact`. `Strata.World.Op` needs readers for its fields: add `op_fields(o : Op) : (Int, List(Int))` (tag 0 cell, 1 box, 2 sphere; its Ints in constructor order) to `Strata.World` in this task if no such reader exists on `main`. Lists keep their order through a round trip. Entity snapshots are written as their three arrays, length-prefixed.

### Task 2: The store's files: atomic writes, open, refusals, the lock

**Files:**
- Create: `lib/strata/save.march`, `test/save_test.march`
- Modify: `lib/strata/blocks.march` (one function), `lib/strata/terrain.march` (one function)

**Interfaces — Produces**
```
Strata.Blocks.fingerprint(r : Registry) : Int     -- a hash over every registered id's flags, style, layer and family, in id order; textures excluded
Strata.Terrain.generation_version() : Int          -- 1; raised whenever Strata's built-in generators change their output

Strata.Save (alias Sv):
type Store
fn identity(dir : String) : Option((Int, Float, Int))            -- (seed, scale, generator version) from store.bin, or None
fn open(dir : String, w : Strata.World.World, generator_version : Int) : Result((Store, Strata.World.World), String)
fn open_forcing(dir : String, w : Strata.World.World, generator_version : Int) : Result((Store, Strata.World.World), String)   -- takes over a stale lock
fn close(s : Store) : Unit                       -- in this task: writes the header and removes the lock; Task 6 makes it flush
fn dir(s : Store) : String
fn stats(s : Store) : (Int, Int, Int, Int)      -- dirty regions, writes in flight, writes failed, files set aside
fn reason(s : Store) : String                    -- the last refusal or failure, "" if none
fn region_of(x : Float, y : Float, z : Float, scale : Float) : (Int, Int, Int)
fn region_of_key(k : Strata.Coord.Key) : (Int, Int, Int)          -- level-0 keys; floor division by 8, negative keys included
-- internal, used by later tasks and their tests:
fn write_atomic(path : String, b : Bytes) : Bool                 -- <path>.tmp then rename; false on any failure
fn read_file(path : String) : Option(Bytes)
fn set_aside(path : String) : Unit                               -- rename to <path>.bad
```
Layout: `<dir>/store.bin`, `<dir>/store.lock`, `<dir>/players/<id>.bin`, `<dir>/regions/r.<x>.<y>.<z>.bin`. `open` on a missing or empty folder makes the folders and a header from the world (seed, scale, fingerprint, the combined generator version) and writes it. `open` on an existing store: deletes leftover `*.tmp`, decodes `store.bin` (damaged: set aside, refuse "damaged header"), then refuses with a reason on a different fingerprint ("different block registry"), seed ("different seed"), scale ("different voxel scale") or a lock present ("open in another game"). A different generator version does not refuse (owner's decision: seams); the store keeps the stored version for regions and records the new one at the next header write. The combined generator version is `generator_version * 65536 + Strata.Terrain.generation_version()`. The lock file holds a random token; `close` removes it only if it still holds this store's token. `open` turns on `Strata.World`'s change log (Task 3) — until Task 3 lands, leave that call out and note it.

### Task 3: The world gives up written chunks and logs its changes

**Files:**
- Modify: `lib/strata/world.march`, `test/world_test.march`

**Interfaces — Produces** (`Strata.World`)
```
fn log_changes(w : World, on : Bool) : World                    -- off by default; while off nothing is recorded
fn take_changes(w : World) : (World, List(Strata.Coord.Key))   -- level-0 keys edited, unloaded edited, queued, or edited back since the last take
fn region_values(w : World, keys : List(Strata.Coord.Key)) : (List((Strata.Coord.Key, Strata.Chunk.Chunk)), List((Strata.Coord.Key, List(Op))))
    -- for those keys: every chunk that differs from its generation (loaded, compacted, or cached) and every queue; a key edited back gives nothing
fn release_written(w : World, written : List((Strata.Coord.Key, Int))) : World
    -- for each (key, content hash) written to disk: if the key is cached (not loaded) and its cached content still has that hash,
    -- drop it from the cache and keep its level-1 coarsening in its place; anything edited since the write is kept
fn held_coarsened(w : World) : Int                              -- how many level-1 summaries are kept
```
The world gains two stores beside its ten fields (a change log and the summaries); every match on `World(...)` in the module is updated. `edits_under` (the far field's capture of fine chunks under a coarse key) must also consult the summaries, so a coarse chunk over a released edit equals the one built before the release. The level-1 coarsening uses the far field's existing code (`coarsen_over` with the chunk as the only fine chunk under its level-1 parent, or the helper it calls; read it on `main`). `insert` of a key that has a summary but no cached chunk generates as usual (the store, Task 5, supplies the saved chunk); its summary is dropped when the chunk loads.

### Task 4: Saving as it plays

**Files:**
- Modify: `lib/strata/save.march`, `test/save_test.march`

**Interfaces — Consumes:** Tasks 1-3. **Produces** (`Strata.Save`)
```
fn tick(s : Store, st : Strata.Stream.Stream, dt : Float) : (Store, Strata.Stream.Stream)
fn set_section(s : Store, name : String, b : Bytes) : Store          fn section(s : Store, name : String) : Option(Bytes)
fn set_region_section(s : Store, region : (Int, Int, Int), name : String, b : Bytes) : Store

```
`tick`: take the world's changes (`Strata.Stream.world`, then put the world back), mark their regions dirty with a quiet clock of 2.0 s reset by every new change; collect writes started two ticks ago and, for each success, call `Strata.World.release_written` with the chunks it wrote and update the decoded-region cache with what was written; start at most one region write, the dirty region whose quiet clock ran out longest ago, as a `Task` carrying the region's values (`region_values` for its 512 keys, plus its sections and the store's current generator version and counter) that encodes and writes `regions/r.x.y.z.bin`, or deletes the file when the region holds nothing; rewrite the header (sections, entity snapshot, generator version, counter + 1) when anything in it changed and 5.0 s have passed since the last header write, also as a task; write a player file when its record changed, the same way. A failed write leaves its region dirty, is counted, and sets `reason`. A region is read from disk before its first write in a session (so its sections and the chunks of its keys not in memory survive the rewrite): through the decoded-region cache, loaded on the frame the first time only if Task 5 has not already cached it.

### Task 5: Loading through the stream

**Files:**
- Modify: `lib/strata/stream.march`, `lib/strata/save.march`, `test/save_test.march`, `test/stream_test.march`

**Interfaces — Produces**
```
Strata.Stream.with_store(s : Stream, regions : Strata.Save.RegionSource) : Stream    -- generation consults saved regions
Strata.Save.region_source(st : Store) : RegionSource                                 -- what generation tasks are handed: the folder and a snapshot of the decoded-region cache
Strata.Save.edited_keys(st : Store) : List(Strata.Coord.Key)                         -- every level-0 key with a saved chunk or queue, from the region files present
Strata.Save.adopt_regions(st : Store, got : List(((Int, Int, Int), Strata.Savefile.Region))) : Store  -- regions generation tasks read, into the cache (main thread)
Strata.Save.reads(st : Store) : Int                                                  -- region files read since open (test hook)
```
A generation task for a level-0 key whose region is in the handed snapshot of the cache uses it; otherwise it reads and decodes that region file itself and returns the decoded region with its result, and the stream hands decoded regions back to the store (`Strata.Save.adopt_regions`) on the main thread, so the cache is only ever changed there. A saved chunk takes the generated one's place and saved queued edits are applied, exactly as `Strata.World.insert` treats its cache: the task returns the generated chunk's hash too, so a saved chunk later edited back to the generation is recognised. A region with a different generator version than the store's current one is used as it is (seams). A damaged region file is set aside, counted, and generation proceeds as if it were absent. Within one tick, at most one task per region reads its file; other keys of that region wait for the next dispatch (state in the ledger how this is enforced). A stream with no store behaves exactly as today.
