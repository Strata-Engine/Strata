Task 1: Ruling: every file is a frame: magic (u32), format version (u8, 1), body length (u64), the body, CRC-32 (u32) of every byte before it from the magic on; little-endian throughout — the brief's `finish` plus a body length, so `reader` can tell a cut file ("truncated") from a damaged one ("checksum") before it trusts any byte — 17 bytes of frame a file; `reader` checks, in order, magic ("not a Strata file"), version (above 1 "newer format", 0 "unknown format version"), the body length against the file's (short: "truncated"; long: "length"), then the checksum.
Task 1: Ruling: the magic numbers are "STRH", "STRR" and "STRP" read as little-endian u32s: header 1213355091 (0x48525453), region 1381127251 (0x52525453), player 1347572819 (0x50525453) — controller ruling (d) — a file's first four bytes spell its kind in a hex dump.
Task 1: Ruling: the checksum is CRC-32 with the reflected IEEE polynomial 0xEDB88320 (zlib's and PNG's), table-driven in March, every value within 32 bits so nothing can overflow; it is exported as `Strata.Savefile.crc32(b : Bytes) : Int`, checked against the standard value cbf43926 for "123456789" — the brief — one more public function than the brief lists.
Task 1: Ruling: primitives: u8 one byte, u32 four, i64 eight (two's complement), f64 eight (IEEE 754 bits, low word first), bytes and strings an i64 length then the bytes (a string's UTF-8 bytes); an i64 outside March's 63-bit Int (-2^62..2^62 - 1) reads as an error, never a wrapped value — March Ints are 63 bits, so the brief's round trip of 2^62 is tested at 2^62 - 1, the largest Int — no file this module writes holds such a value.
Task 1: Ruling: March cannot see a Float's bits, so f64 and f32 bits are worked out from the value: the exponent from log2 corrected against pow(2, e), the mantissa by exact scaling; subnormals, both infinities and -0.0 (found with atan2(0, v), since 1 / -0.0 traps on March main) keep their bits; every NaN is written as the quiet NaN 0x7FF8000000000000 (0x7FC00000 as f32) — no float-bits builtin (stdlib msgpack notes the same lack) — a NaN's payload is not kept; the encoding relies on libm's pow(2, n) being exact, which the round-trip property over exponents -1100..1030 checks.
Task 1: Ruling: a Writer is a growable native byte array (doubling) with the frame's 13 front bytes reserved, filled in at `finish`, which converts to Bytes once (`Bytes.from_u8_arr` and one slice); `encode_region` sizes its buffer from its chunks' forms first, and a paletted chunk's indices are written straight into the buffer as its palette is built — controller ruling (e); repeated `Bytes.concat` would copy the whole file at every step.
Task 1: Ruling: a chunk is its key (four i64s: x, y, z, level) and its form byte (Strata.Chunk.form) then: 0 uniform, the id (u16); 1 paletted, 32768 palette indices (u8, flat index order), the palette's size n (u16, 1..256) and n ids (u16); 2 direct, 32768 ids (u16) — ids are 0..65535 by Strata.Chunk's own rule, so u16 holds them; the palette is rebuilt from the content in first-use order (Strata.Chunk's form is private) through one 65,536-entry id-to-slot table the whole region shares, cleared slot by slot after each chunk; a paletted chunk found to hold over 256 ids (impossible by Strata.Chunk's invariant) is written direct rather than wrongly — a paletted chunk costs 35,331 bytes at most, a direct one 65,569.
Task 1: Ruling: a decoded paletted or direct chunk is built with `Strata.Chunk.from_flat`, the function `compact` is made of, so it arrives in its smallest form without a second pass; a palette size outside 1..256 or an index past the palette is an error — the brief's "passes through compact" — a direct chunk with 256 or fewer ids comes back paletted (the tests compare forms against `compact` of the original).
Task 1: Ruling: an op is its tag (u8: 0 cell, 1 box, 2 sphere) and its Ints as i64s in constructor order, read and made through the new `Strata.World.op_fields(o) : (Int, List(Int))` and `op_cell`, `op_box`, `op_sphere`; another tag is an error — the brief — `op_fields` is the only change to Strata.World.
Task 1: Ruling: region layout: generator (i64), counter (i64), chunks (u32 count; key, chunk each), queued ops (u32 count; key, u32 count, ops each), sections (u32 count; name string, bytes each), and nothing after — design section 3 — lists keep their order.
Task 1: Ruling: header layout: seed (i64), scale (f64), fingerprint (i64), generator (i64), counter (i64), sections (u32 count; name, bytes each), then a snapshot flag (u8: 0 none, 1 present; anything else an error) and, when present, the int32 array (u32 count, each as u32 two's complement), the float32 array (u32 count, each its f32 bits as u32) and the double array (u32 count, each f64) — controller ruling (a), the arrays opaque, Strata.Entities not imported.
Task 1: Ruling: player layout: the game's bytes as one length-prefixed field (i64 length, bytes), nothing after; `decode_player` answers a fresh Bytes — controller ruling (b).
Task 1: Ruling: decoding never panics: every read checks the bytes it needs against the body's end; a byte length larger than the bytes left, and a count larger than the bytes left divided by its item's least size (16 a section, 35 a chunk, 36 a queued key, 33 an op, 4 or 8 an array value), are errors before anything is allocated (division, so a huge count cannot overflow a product); no read is guarded by `&&` or `||` (GAPS S16, S26); inside, decoders run on a sticky reader that keeps the first failure and reads zeros after it, and answer that failure as the Err — Review Focus 4 — the reason names the first thing found wrong, not every problem in the file.
Task 1: Ruling: the brief's `Header` and `Reader` are named `SaveHeader` and `SaveReader`: March has one type namespace for the whole program, and `Header` collided with the standard library's `Http.Header` (a type error at the first use: "Two distinct types are both named `Header`"), `Reader` with `Strata.Fluid.Reader`; constructors are prefixed `Sf` (GAPS S18) — `Writer` and `Region` keep their names; later tasks use `Strata.Savefile.SaveHeader`.
Task 1: Ruling: the test module's alias for Strata.Savefile is `Svf`: `Sf` is already Strata.Surface's in test/surface_test.march (GAPS S6); types are written by their full paths in signatures (`Strata.Savefile.SaveReader`), as the other tests do, since an alias did not resolve in a type position ("Unknown module `Svf`").
Task 1: Ruling: the 512-chunk region encode (paletted ground chunks, 16.8 MB) costs 266 ms of CPU (user, release build, mean of 10; 44 ms more of system time); its decode about 277 ms; CRC-32 of the 16.8 MB about 74 ms of that — not judged (load 71); recorded against Task 4's 50 ms budget, which this does not meet: each pass over a chunk is a March loop of about 5 ns a voxel (Strata.Chunk.hash over the same 512 chunks costs 103 ms).
Task 2: Ruling: the brief's `Store` is named `SaveStore`: `Strata.Store.Store` already exists and one type namespace serves the whole program (the suite failed to typecheck in test/store_test.march with "expected `Store(b)` but got `Strata.Store.Store(Int)`") — as Task 1's `SaveHeader` — later tasks use `Strata.Save.SaveStore`.
Task 2: Ruling: `Strata.Blocks.fingerprint` is FNV-1a over 63-bit Ints (multiplying with `int_wrapping_mul`) of: the id count; for each id in order its flags byte (collision, opacity, layer, style, fluid bit), model index, emission, material word (roughness, emissive, sound), family base and size, and the five physics values; then the model count and each model's collision boxes (count, then six coordinates in 1/2^20ths, NaN as 0, clamped to +-10^6); face textures and model drawing quads are left out — controller: every field that changes what a block is, textures excluded — a game that only re-textures keeps its saves; changing a block's sound or physics refuses them.
Task 2: Ruling: the lock token is the process id and the clock in microseconds ("<pid>-<micros>", from `Process.pid` and `System.now`), with "+" added if the folder's lock already holds that string; `Crypto.random_bytes` needs `IO.Random`, which a library module charges to every test module in the suite (the build stopped at test/acoustics_test.march: "uses `IO.Random` but does not declare `needs IO.Random`") — controller ruling (b), GAPS S48 — `Strata.Save` declares `needs IO.FileSystem`, `IO.Clock` and `IO.Process`, so a game using it declares them too.
Task 2: Ruling: `open` checks the lock first, before it makes folders, deletes any `.tmp` or sets a damaged header aside, so a folder another game holds is never touched; then folders, `.tmp` sweep (in the store, regions/ and players/), header (damaged, unreadable, newer format, registry, seed, scale, in that order); the lock is looked for again just before it is written (Task 3), then written and read back, and a lock that does not hold this store's token after the write refuses ("open in another game") — the brief lists the lock last among the refusals; deleting a live game's `.tmp` would break its rename — check-then-write is not atomic (March has no exclusive create): the read-back only catches a rival whose write lands between this store's write and its read; two games that both pass the second look before either writes can both open, so the window is that one write, not two games "within one write of each other" whatever they did before it (corrected in Task 3).
Task 2: Ruling: refusal reasons are fixed strings: "open in another game", "damaged header" (the file set aside as store.bin.bad), "unreadable header" (store.bin there but not readable), "newer format" (not set aside: a newer Strata can still read it), "different block registry", "different seed", "different voxel scale", "no header" (a folder holding files but no store.bin, e.g. after a damaged header was set aside: it is not taken for a new store and written over), "cannot make the store's folders", "cannot write the header", "cannot write the lock" — design section 9 and the brief — a game shows them as they are.
Task 2: Ruling: a new store's header has counter 1 (the counter is raised on each header write, from 0), no sections and no entities; `close` writes the header (counter raised, generator version the one the game opened with) and removes the lock only when the lock still holds this store's token; a store taken over by `open_forcing` writes nothing at close — Review Focus 3 — the second game's header is not clobbered by the first.
Task 2: Ruling: `open` does not yet turn on Strata.World's change log (Task 3 adds it); it hands the world back unchanged — controller ruling (a). Superseded in Task 3.
Task 2: Ruling: `region_of(x, y, z, scale)` is floor(v / (256 * scale)) per axis, an axis that is NaN or infinite, or a scale that is not positive, answering 0 (float_floor traps out of range on March main); `region_of_key` floor-divides by 8, and a level-L key (L > 0) answers the region of its first level-0 chunk (coordinates times 2^L, L capped at 24) — controller ruling (e) — total, no panic.
Task 2: Ruling: test stores are folders `test/.scratch/<test>-<pid>-<ms>`, removed at the end of each test (`Dir.rm_rf`); `test/.scratch/` is in .gitignore — controller ruling (c).
Task 3: Ruling: `open` and `open_forcing` hand the world back with `Strata.World.log_changes(w, true)`; when not forcing, `open` looks for the lock again right before writing its token (the first look stays first, before anything is touched), so a game that took the lock while this one read the header is refused; Task 2's ledger line on the read-back is corrected — controller rulings (a) and (b) — Task 2's test "open hands back the world unchanged" is now "open hands back the world with its change log on" (both opens).
Task 3: Ruling: the change log is the world's eleventh field, `Option(Strata.Store.Store(Bool))`: None while off (each recording site is one match on None, nothing allocated), a set of level-0 keys while on; `log_changes(w, false)` drops it, turning it on twice keeps it; `take_changes` answers its keys and empties it — design section 4: a game without a store pays nothing.
Task 3: Ruling: the log records every `replace_chunk` of a loaded level-0 chunk (each cell, box, sphere or bulk edit Strata.Edit applies), every `enqueue`, and every `unload` that moves a chunk to the cache; an edit that returns a chunk to its generation is a `replace_chunk` like any other, so "edited back" is recorded with no hash at edit time — controller ruling (c) — a chunk loaded from the cache and unloaded untouched is recorded again (it differs, so it goes back to the cache): a spurious dirty region, never a lost one.
Task 3: Ruling: `log_changes`'s parameter is `enabled`, not the brief's `on`: `on` is the actor keyword and cannot name a parameter (GAPS S4, S29, S36) — the signature is otherwise the brief's.
Task 3: Ruling: `region_values(w, keys)` is pure: for each key once, in the keys' order, a loaded chunk that differs from its generation (compacted with `Strata.Chunk.compact`), else a cached chunk (already compact); and a queue, oldest edit first (the world keeps them newest first; `enqueue` them in the given order to restore); a loaded chunk edited back gives nothing, and so does a key held only as a coarse copy — controller ruling (e) — Task 4 must not take a key missing from `region_values` as "delete from disk" when that key is a released chunk: it is on disk and only there.
Task 3: Ruling: a released chunk's coarse copy (`HeldCoarse`: `HcOne(id)`, `HcPal(u8 indices, palette)` up to 256 ids, else `HcAll(i32 ids)`) holds what the chunk coarsens to at level 1 (16^3) and also at levels 2 to 5 (8^3, 4^3, 2^3, 1): 4681 voxels, each the far field's own `cube_id` of its 2^L cube with the registry's table, in `lay_go`'s order — controller ruling (d) and the brief's "the helper it calls" — a level-1 copy alone would make level 2 and up from coarsened voxels (the most common of eight winners is not the most common of 64 voxels), so a coarse chunk over a released edit would change at the release; 585 voxels more (14%) make every level equal, and the far-field test checks levels 1 and 2. Paletted, a copy is 4681 bytes plus its palette, about a seventh of a paletted chunk; making one costs five passes over the chunk (one per level).
Task 3: Ruling: `Fine` gains a second constructor, `FineHeld(key, HeldCoarse)`, captured by `edits_under` from the coarse copies as it captures cached chunks, always edited, laid by `lay_held` into the same voxels `lay` would fill; `coarsen_over`, `edited` and `lay_all` read both; Strata.Stream passes `Fine` along untouched — controller ruling (d), "the smallest change" — `edits_under` gives one entry per edited fine chunk whether it is cached or released, and `coarsen_over` the same chunk (equal by `Strata.Chunk.hash`).
Task 3: Ruling: `release_written` compares `Strata.Chunk.hash` of the cached (compacted) chunk with the hash written; a loaded key, a key not cached, or a hash that differs (edited since the write) is left alone; the coarse copy is dropped when the key loads (`insert`); the coarse copies are independent of the generator (each covers its own octant whole), so `regenerate` keeps them, with the cache, queues and log — controller ruling (f), design section 4.

Task 4: Ruling: the store's clock is the sum of the `dt`s given to `tick` (a NaN or negative dt counts 0); a dirty region keeps the time of its last change, the set of level-0 keys changed since its last write and the region sections set since then; `stats`' first number is the dirty regions with no write started — the brief — one region write is started a tick, the region whose last change is oldest among those quiet 2.0 s with no write of it in flight.
Task 4: Ruling: a region write is made from the region as the disk holds it (the decoded cache; read on the caller's thread before the region's first write when no generation task has loaded it) and only the keys that changed: a key the world gives a chunk for (`region_values`) is put; a key the world gives none for is dropped when it is loaded (edited back to its generation) and kept when it is away (released, or never loaded this session: its chunk is on disk and only there) — Task 3's ruling on `region_values` — the cost of starting a write follows what changed, not the region's 512 keys.
Task 4: Ruling: queues: a key whose chunk is in memory (put or dropped) has the world's queue alone; a key that is away has the saved queue followed by the world's, less the longest start of the world's queue the saved queue already ends with (a write that already appended it) — the world keeps its queue until the chunk loads, so the next write would append it again — applying a queue's tail twice changes nothing (each edit overwrites), so a coincidental overlap costs nothing either.
Task 4: Ruling: the worker hashes each chunk it puts and compares with the saved chunk's hash; a region that comes out as the disk holds it is not written (a saved chunk loaded, never edited and unloaded goes to the world's cache and is logged, Task 3; the worker finds it unchanged and it is released without a write); a region holding nothing has its file deleted — Review Focus 2 — hashing stays off the caller's thread.
Task 4: Ruling: a region file keeps the generator version it was first written with; a rewrite does not raise it — design: "every region records the generator version that wrote it, so a game can find the seams" — a region whose chunks were edited under two generators reports the older.
Task 4: Ruling: `tick` never waits for a write: it polls (`task_poll`) every write in flight each tick and folds in those that have finished; the plan's "collect writes started two ticks ago" is the stream's rule for work it then waits for, and a region write can take hundreds of milliseconds (Task 1's measurement) — design: "saving never makes a frame late" — `wait_writes` and `flush` wait.
Task 4: Ruling: a failed write (the task's write or rename failing, or the task itself) is counted, sets `reason` ("cannot write region r.x.y.z", "cannot write the header", "cannot write player N"), and leaves its region dirty with a fresh quiet clock, so it is tried again 2 s later, not every tick; nothing was released, so its chunks stay in the world — Review Focus 1.
Task 4: Ruling: the world gives up at most 2 written chunks a tick (`release_written` hashes the cached chunk and makes its coarse copy on the caller's thread, about five passes over a chunk); `wait_writes` and `flush` release all — design: no hitch when the world saves — after a big write the cache empties over some frames.
Task 4: Ruling: a written chunk the stream is generating at that moment (`Strata.Stream.generating`: its task running, or its chunk waiting to be applied) is not released until it is not: the task may have read the region before the write, and the world's cached copy taking the generated chunk's place is what makes its result right — design, Risks 1 — such a chunk stays owed and is released on a later tick (or stays cached if it loads, as any loaded chunk's is dropped at `insert`).
