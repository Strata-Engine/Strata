# SDD ledger — plan: docs/2026-11-19-shapes-plan.md
Spec: docs/2026-11-19-shapes-design.md.

Design: Ruling: a shape's voxels are block ids in memory (`Strata.Body.Grid`, unchanged); the palette is derived (the distinct ids, at most 255) and is what a save writes a byte a voxel against. Physics, fracture, support and the mesher read ids, and a body cut from the world is a piece of the world's ids, so a palette byte in memory would put a translation on every hand-over and change physics while another session repairs it — none.
Design: Ruling: props are drawn by the body path (a slot at a pose with its own voxel size, its light classes in the rays' table), not the figure path the population design named: the body path did not exist in that form when the population design was written; it draws the game's textured blocks, is traced for sun and sky, and is what a prop becomes when it falls, so nothing changes look mid-fall — supersedes population design section 9 "Drawn and lit" and "Shade" (no leaf occupancy is written into the light volume).
Design: Ruling: static shapes live in `Strata.Shapes`, outside physics (physics walks a list of at most 4,096 bodies each step); a prop knocked loose is handed to `Strata.Physics.add_shape` as the same grid value — none.
Design: Ruling: no per-face "disconnected" bit; face connection and the held rule are enough for what is built — the brief made it optional.
Design: Ruling: a layer is a prop layer only when it says so (`props`); the population design's "detail scale defaults to 0.25 m for every layer" would turn every stamped layer of the island into props and change every stored golden. The viewer places props under `STRATA_PROPS=1` — owner to flip the default when goldens are re-stored.
Design: Ruling: an edit reaches a prop by region (`carve_sphere`, `carve_box`), not by change records: a prop stands in the world's air, where an edit records no change — none.
Task 1: Ruling: `Strata.Shape.grid_of(template, rot)` bakes the quarter turn into the grid and keeps every non-hole voxel: a template's probabilities are not drawn, because every instance of a variant shares the grid (the viewer's trees use none) — a placed prop's rotation is the identity and its voxels sit on the fine lattice; one prototype a variant and turn.
Task 1: Ruling: `Shape.ray` answers a `Strata.Query.Hit` whose voxel and face are in the grid's own frame; `carve_sphere` takes every voxel that is not air (leaves too), where `Strata.Physics.cut` takes only colliding ones — none.
Task 1: Ruling: `Shape.parts`: the held parts together are the standing shape in a grid of the first size (the pose does not change); a loose part under 8 colliding voxels is a crumb, counted and dropped (physics' fragment size; a fine fragment cannot land in the world's cells); voxels that do not collide belong to no part (`Strata.Body.split`) and are dropped when a shape is split — a carved tree keeps non-colliding voxels only while it is one held part.
Task 1: Ruling: a grid's bytes are sizes (a byte each), a form byte, a palette (4 bytes an entry) and runs of (length 2 bytes, palette byte); a grid of more than 256 kinds of block is written as runs of ids. Written by hand in `Strata.Shape` rather than through `Strata.Savefile`'s writer, whose reader answers a Result per field — none.

Task 3: Ruling: `Strata.Shapes` does not read `Strata.Save` (whose `needs` would be charged to every user): it answers the regions it meets (`take_regions`) and the bytes of regions whose memory changed (`take_dirty`), and takes bytes in (`adopt`); the game moves them through `Strata.Save.region_section` and `set_region_section` under the name `shapes`. A region is 8 chunks a side, as Save cuts them — the viewer's `store_shapes` is the eight lines a game writes.
Task 3: Ruling: `adopt` gives a chunk the saved memory only where it has none, and stands the chunk again if its props already stand, so the order in which a region's section and a chunk's props arrive does not matter — none.

Task 3: Ruling: `Shapes.changed` takes the two lists of `Strata.Stream.take_changed` (and `sync` takes them itself): the stream is not changed.
